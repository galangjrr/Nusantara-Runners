# Roblox Indonesia Marathon Runner - Codebase Pipeline

Folder project utama untuk Roblox Indonesia Marathon Runner Simulator.

## Project Structure
- `src/Server/`: Script server (DataManager, GymService, RaceService, StraviService, GearService)
- `src/Client/`: Script client (CadenceController, StraviHUD, CoachHUD, ShopHUD)
- `src/Shared/`: Shared modules & config (Config.luau, Remotes setup)
